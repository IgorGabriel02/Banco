*PROJETO DE BANCO EM JAVA*
Projeto básico de sistema bancário simples no terminal afim de praticar conceitos fundamentais da programação orientada a objeto.
O projeto possui a criação de um usuário(Objeto) e disponibiliza a ele 4 opções ( Sacar saldo , Depositar saldo , Consultar saldo ou fechar o programa), a partir de
qual opção for escolhida pelo usuário através de métodos auxiliares de encapsulamento get e set ele poderá alterar seus atributos caso atenda aos requisitos dos metodos.
Para executar o projeto, certifique-se de ter o Java (JDK) instalado, abra a pasta do projeto no VS Code e acesse o terminal na pasta onde estão os arquivos .java. 
Em seguida, compile os arquivos utilizando o comando javac Main.java Conta.java e execute o programa com o comando java Main.
